高齢者向け宅配食とは

管理栄養士が監修したメニューや、塩分・たんぱく質・カロリーを制限した治療食、刻み食・ソフト食など、高齢者の身体状況に合わせた宅配食サービスです。配達時の対面での安否確認をサービスに組み込んでいる事業者もあり、遠方に住む家族の見守り手段としても利用されています。

こんな方におすすめ

  • 離れて暮らす親の食事・安否が気になる方
  • 塩分・カロリーなど食事制限が必要な方
  • 噛む力・飲み込む力に不安がある方
  • 毎日の調理・買い物の負担を減らしたい介護中のご家族
