ミールキットとは

ミールキットは、レシピと必要な分量にカット・計量された食材が一緒に届くサービスです。

献立を考える手間や買い物の手間を減らせる点が特徴で、共働き世帯や自炊に時間をかけられない方に人気があります。

こんな方におすすめ

  • 毎日の献立を考えるのが負担な共働き世帯
  • 買い物や下ごしらえの時間を減らしたい方
  • 自炊はしたいが料理のレパートリーを増やしたい方
  • 子どもの食事にも野菜をバランス良く取り入れたい方

選び方3つのポイント

①献立を選びたいか、おまかせがよいか

毎回自分でメニューを選びたいタイプと、栄養バランスを考えたメニューがおまかせで届くタイプがあります。自分に合うスタイルを選びましょう。

②食材の質・栄養バランス

旬の食材にこだわるサービスや、管理栄養士監修のメニューを展開するサービスなど、特徴はさまざまです。重視したいポイントを整理しましょう。

③配送頻度・置き配対応

毎日届くタイプや週数回タイプなど配送頻度が異なります。受け取りやすさ（置き配対応の有無など）も比較のポイントです。
