気になる点

デメリットと対策

案内の他には、次のような声も見られます。

  • カット野菜など一部食材の賞味期限が2〜3日と短い
  • レシピによっては表示時間より調理に時間がかかる

賞味期限については到着後早めに使い切る、調理時間については慣れないうちは簡単なメニューから試すことである程度対策できると考えられます。なお、おためしセットは1世帯1回限りの利用となっている点にも注意が必要です。
