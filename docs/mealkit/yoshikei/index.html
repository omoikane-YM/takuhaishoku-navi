ヨシケイ「お試し5days」とは

1965年創業の食材宅配サービス「ヨシケイ」が提供する初回限定のお試しキャンペーンです。平日5日分の食材とレシピがセットになったミールキットを、通常価格の半額程度で体験できます。入会金・年会費・配達料は無料で、置き配にも対応。時短重視から栄養バランス重視まで、ライフスタイルに合わせて選べる複数のコースが用意されている点が特徴です。

コースの種類

大きく「時短系」「家庭料理系」「プレミアム系」の3タイプ、8コースから選べます。

メリット

良い評判として多く見られる点

  • 「夕食作りが楽になった」という献立を考える負担軽減への評価が多い
  • レシピ付きなので料理のレパートリーが増えるという口コミ
  • 「勧誘が控えめ」「不在時の置き配が便利」という利用しやすさの評判
  • 入会金・年会費・配達料が無料で、お試しのみの利用も可能

気になる点

  • 「量がやや少ない」「食材の品質が普通」という声もある

量については、世帯人数の設定を見直したり、副菜を1品足すことで調整している利用者もいるようです。まずはお試し5daysで自分の家庭に合うコースを見極めてから、本申し込みを検討する使い方が見られます。

デメリットと対策

量や品質の他には、「レシピに慣れるまでは表示時間より調理に時間がかかる」「お試し期間中は決められたコースのみで、その日ごとの変更はできない」といった声も見られます。調理時間については、まずは時短系コースから試してみることである程度対策できると考えられます。
