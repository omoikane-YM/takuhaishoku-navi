食のそよ風とは

株式会社SOYOKAZEが運営する、管理栄養士監修の冷凍宅配食サービスです。定期購入のリピート率は92.4％と高く、時短で理想の食生活を叶えるコスパ・タイパの良さが特徴です。

健康的な食生活を目指す方からダイエット・トレーニング中の方、忙しい働き世代、子育て夫婦、一人暮らしまで、幅広いライフスタイルに合わせたメニューを展開しています。

メリット

良い評判として多く見られる点

  • リピート率92.4％という高い継続率への評価
  • 「たんぱく質・食物繊維を1食でまとめて摂れる」という手軽さの評価
  • 管理栄養士監修でPFCバランスが整っているという安心感
  • お届け回数に応じて送料が最大25％OFFになるお得な定期特典

気になる点

  • 定期購入を6回未満で途中解約すると、送料の差額を別途請求される

送料の差額請求については、まずはお届け回数の少ないコースから試し、続けられそうであれば回数を増やすといった使い方で対策できると考えられます。

デメリットと対策

送料の条件の他には、次のような点も確認しておきたいポイントです。

  • 調味料・ハーブ・一部加工品には外国産のものも含まれる商品がある(国産プレミアムの場合)
  • 商品によって価格帯が異なるため、目的に合わせて選ぶ必要がある

食材の産地が気になる方は、国産食材にこだわった「国産プレミアム」を中心に選ぶと安心です。
