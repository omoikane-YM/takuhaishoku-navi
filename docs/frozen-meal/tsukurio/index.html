ツクリオとは

株式会社Antwayが運営する「つくりおき.jp」がリニューアルした手料理サブスクです。調理経験豊富なシェフと管理栄養士が監修し、専用キッチンで手作りしたお惣菜を毎週ご家庭に冷蔵でお届けします。

電子レンジ調理や冷凍保存が不要で、届いたその日にそのまま食卓へ並べられるのが特徴です。注文・休止・解約はLINEで完結し、定期縛りもありません。

メリット

良い評判として多く見られる点

  • 冷凍ではなく冷蔵で届くため、出来立てに近い状態でそのまま食卓に出せる
  • シェフ×管理栄養士監修で「家庭では手が回らない味」が楽しめるという評価
  • 注文・お休み・解約がLINEで簡単、定期縛りがなく続けやすい
  • 子育て世代・共働き世帯から「夕食づくりの負担が減った」という声

気になる点

  • 冷蔵配送のため、冷凍弁当のようなストック買いはできない

ストックしにくい点については、毎週決まったタイミングで受け取れるよう配送スケジュールを固定して運用している利用者が多いようです。まずは初回クーポンを使って、自分の生活リズムに合うか試してみるとよいでしょう。

デメリットと対策

ストックのしにくさの他には、次のような点も確認しておきたいポイントです。

  • 冷蔵配送のため、受け取りタイミングをある程度固定する必要がある
  • 初回オファーは4人前プランが対象で、2人前プランには適用されない場合がある

受け取りタイミングについては、置き配や不在時の対応が可能かどうかを事前に公式サイトで確認しておくと安心です。
