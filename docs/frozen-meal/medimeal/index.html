メディミールとは

メディミールは、看護師・理学療法士・言語聴覚士で構成される医療の専門チームが監修し、管理栄養士が栄養バランスを考えながら献立を立てている宅配制限食サービスです。食品添加物や合成着色料をできるだけ避け、国産を中心とした素材を自社工場で手づくりしています。

管理栄養士が常駐しており、制限食の選び方や食生活について電話で相談できる体制も特徴のひとつです。全国配送に対応しています。

メリット

  • カロリー・糖質・塩分・たんぱく質など7種類の制限食から自分に合うものを選べる
  • 管理栄養士に電話で相談できる体制があるという評判
  • 初回送料無料・会員登録ポイントなど、気軽に試しやすいキャンペーン

気になる点

  • 制限食専門ゆえにメニューの種類が多く、自分や家族に合うコースを選ぶのに迷うという声もある

公式サイトの各コース説明（カロリー・糖質・塩分・たんぱく質の基準値）を見比べたうえで、かかりつけ医や管理栄養士に相談しながら選ぶとミスマッチを防ぎやすいようです。

デメリットと対策

コース選びの他には、次のような点も確認しておきたいポイントです。

  • 制限食という性質上、通常の宅配弁当よりも味付けが控えめに感じる場合がある
  • 全国配送だが地域によって到着まで日数がかかる場合がある

初回はお試しセットで味の傾向を確認し、管理栄養士への電話相談を活用することで、自分に合った制限食を見つけやすくなります。
