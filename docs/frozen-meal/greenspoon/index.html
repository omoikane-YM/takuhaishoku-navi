GREEN SPOONとは

「たのしい野菜が、いつもすぐそこに」をコンセプトに掲げる野菜特化型の宅配食サービスです。

ミシュラン経験のあるシェフが監修したレシピを、料理ごとに「紙包み」「素材ゴロゴロ」など最も美味しく食べられる調理方法で製品化しています。

管理栄養士とともに栄養バランスの良いレシピを開発しており、過度な低カロリー・低糖質に偏らせず、美味しさと健康的な食生活の両立を重視した設計になっている点が特徴です。冷凍で届き、レンジで約5分温めるだけで食べられます。

メリット

良い評判として多く見られる点

  • 「ゴロゴロ具材でお腹にたまる」「ボリュームがあって満足感がある」という口コミが多い
  • 低カロリー・低糖質でも味が本格的という評価、パッケージやフレーバー名の可愛さも好評
  • ミシュラン経験シェフ監修＋管理栄養士設計で、味と栄養バランスの両立を重視した商品設計
  • レンジ約5分で調理でき、忙しい日でも野菜を手軽に摂れる利便性

気になる点

  • 1食あたり811〜1,053円と、他の冷凍宅配弁当と比べて価格はやや高めという声が多い

価格については、野菜の質・種類の豊富さやシェフ監修レシピという付加価値に対する対価と捉える利用者が多いようです。まずは単品プランやお試しボックスで味・ボリュームを確認してから定期プランを検討する、という利用の仕方が見られます。

デメリットと対策

価格の他には、次のような声も見られます。

  • ヘルシー志向のため味付けがあっさりめで、好みが分かれる
  • パウチ容器のためお皿に移し替える手間がある
  • 冷凍庫のスペースを取る

味の好みについては単品プランで事前に試すことである程度対策できます。冷凍庫スペースについては、定期プランの食数を家庭の冷凍庫容量に合わせて調整することで対応している利用者もいるようです。

こんな人におすすめ

  • ワンオペ育児・仕事などで自分の食事が雑になりがちな方
