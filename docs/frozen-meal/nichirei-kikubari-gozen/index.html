気くばり御膳とは

日本で初めて冷凍加工食品を生み出した「冷凍食品のリーディングカンパニー」株式会社ニチレイフーズが手がける、冷凍のおかずセットです。健康に美味しさも“気くばり”した和・洋・中の多彩なラインナップで、毎日のカロリーコントロールを無理なく続けられるよう設計されています。冷凍だから長期保存が可能で、食べたいときに電子レンジで温めるだけで食卓に一品追加できます。

調理・盛り付け・包装の各段階で厳しい品質検査を行い、味覚評価員によるレンジ調理後の検食や、全食材をすり潰しての衛生検査も実施していると案内されています。設計どおりの栄養成分で提供できる「品質の確かさ」から、臨床試験用の基準食として利用された実績もあるそうです。
