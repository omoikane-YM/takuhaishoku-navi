トップ > 冷凍宅配弁当 > わんまいる

わんまいる最大の特徴は、国産食材100%・合成保存料不使用の手作りおかずを、専属の管理栄養士と老舗惣菜専門店が全面協力して個包装真空冷凍していること

働くママ・パパを対象にした味評価で第1位を獲得し、累計販売数量360万食を突破した冷凍おかずセット「わんまいる」について、公開されている口コミ・公式情報をもとに、特徴やメリット・デメリットを第三者視点で整理しました。

わんまいるとは

株式会社ファミリーネットワークシステムズが運営する冷凍惣菜の宅配サービスです。専属の管理栄養士が考案したメニューを、大阪・徳島・兵庫・宮崎など全国各地の老舗惣菜専門店や食肉加工会社が手作りで商品化しており、国産食材を100%使用、合成保存料・合成着色料は使用していません。

元帝国ホテル料理長の指導による真空個包装冷凍技術を採用しているのが特徴で、調味料が少なくても味が染み込み、湯せんまたは流水解凍だけで出来立てに近い美味しさを楽しめると案内されています。抜き打ちで行われた日経DUAL食材宅配ランキングでは味・品質部門で1位を獲得し、累計販売数量は360万食を突破しています。

商品ラインナップ・お届け方法

2026年9月時点で公開情報から確認できた内容です。最新の価格・メニュー内容は必ず公式サイトでご確認ください。

商品ライン特徴
健幸ディナー 主菜1品・副菜2品で1食完結。5食平均でたんぱく質20g以上・糖質30g以下・塩分3.5g未満・400kcal以下。1品ずつ個食包装、湯せんまたは流水解凍
美食弁当 食品添加物無添加（きび砂糖・無添加醤油を使用）。国産食材100%・ブランド食材を使用し、5食平均で糖質30g以下・たんぱく質15g以上・塩分2.5g未満・350kcal以下。電子レンジで簡単調理

定期コースは「1週間に1回・1週間分お届け」「2週間に1回・2週間分お届け」から選べると案内されています。メニューは月替わりで重複が少なく、和洋中と豊富に用意されているのも特徴です。

メリット

良い評判として多く見られる点

  • 国産食材100%・合成保存料不使用という原材料への安心感
  • 働くママ・パパからの味評価で第1位を獲得したという実績
  • 1品ずつ個包装されているので、必要な分だけ解凍して使える便利さ
  • 共働きや介護等で買い物・調理の時間を短縮したい家庭からの支持

気になる点

  • 手作り惣菜のため、量産型の冷凍弁当と比べるとメニューの選択肢は絞られている

公式サイトでは「今週のメニュー紹介」が公開されているので、注文前に実際の献立内容を確認しておくとイメージが掴みやすいようです。

デメリットと対策

手作り惣菜という性質上、大量生産の冷凍弁当に比べるとメニューの入れ替わりサイクルや在庫状況によって内容が変わる場合があります。また、物価高や気候の影響で使用食材が変更になることもあると案内されています。

  • 「1週間に1回」「2週間に1回」の定期コースがあり、頻度は好みに合わせて選べる
  • 北海道・沖縄は送料が異なるため、事前に配送条件を確認しておくと安心

まずは公式サイトで今週のメニューや解凍・調理方法を確認し、自分の生活リズムに合う定期頻度を選ぶことをおすすめします。

こんな人におすすめ
