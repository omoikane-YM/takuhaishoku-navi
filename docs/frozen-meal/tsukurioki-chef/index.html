シェフの無添つくりおきとは

株式会社AIVICKが運営する、化学調味料・保存料を使わずシェフが手作りしたお惣菜を週替わりで届ける冷蔵の宅配惣菜サービスです。食材の82%が国産で、中国産食材は不使用です。

管理栄養士（徳島大学の堤理恵先生）が全体の栄養バランスを監修しており、1回の配送で30〜70品目もの食材を使用したメニューが届きます。冷蔵でのお届けのため消費期限は到着から4日間です。

メリット

良い評判として多く見られる点

  • 「原材料がシンプルで安心できる」という無添加品質への評価が多い
  • 化学調味料を使わなくても「味が凝っている」「美味しい」という口コミ
  • 1食あたり8〜11品目の食材を使うなど、栄養バランスの良さが評価されている
  • 初回は割引＋送料無料キャンペーンがあり、気軽に試しやすい

気になる点

  • 2回目以降は送料990円がかかり、他の作り置きサービスと比べて価格はやや高めという声がある

価格については、化学調味料・保存料を使わない分の手間や、国産食材へのこだわりに対する「必要経費」と受け止める利用者も多いようです。まずは初回キャンペーンで味やボリュームを確認してから継続を検討する、という利用の仕方が見られます。

デメリットと対策

価格の他には、次のような声も見られます。

  • 化学調味料を使わない分、味付けが薄めに感じる
  • メニューが選べない（固定の献立）
  • 冷蔵で消費期限が3〜4日と短い

味の濃さについては、無添加ならではのやさしい味わいと捉えている利用者も多いようです。献立はLINEで事前に確認でき、不要な週はスキップできるため、計画的に受け取ることである程度対策できると考えられます。
