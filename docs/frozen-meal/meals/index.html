Mealsとは

レシピ動画メディア「デリッシュキッチン」を運営する株式会社エブリーがプロデュースする冷凍宅配弁当サービスです。おかずは急速冷凍・真空パック仕上げで、国内工場でひとつひとつ手作りされていると案内されています。主菜42種類・副菜100種類という豊富なメニューから、日々の献立に合わせて選べるのが特徴です。

管理栄養士監修のもと、1食あたりカロリー350kcal以下・塩分2.5g以下・野菜量120g以上を基準に設計されており、糖質・脂質・タンパク質・ビタミンC・カリウム・鉄についても基準が設けられています。パッケージは縦17.2cm×横23.0cm×高さ4.5cmと薄型コンパクトで、冷凍庫にも収まりやすい設計です。

メリット

良い評判として多く見られる点

  • 人気レシピ動画メディア「デリッシュキッチン」プロデュースならではの味・メニューの豊富さ（主菜42種・副菜100種）
  • カロリー350kcal以下・塩分2.5g以下など栄養基準が明確で、栄養バランスが気になる方でも選びやすい

デメリットと対策

定期購入は自動更新の仕組みのため、不要な場合はキャンセルまたは停止の手続きが必要です。次回発送予定日の4日前午前7時までに変更手続きを行う必要があると案内されているため、スキップや停止を予定している場合は早めにマイページで操作しておくと安心です。

また、北海道・沖縄県・一部離島は配送料金体系が異なり、お届けまでに追加の日数がかかる場合があります。お住まいの地域の送料・お届け日数は、注文前に公式サイトで確認しておくことをおすすめします。
