RIVERETとは

RIVERET（リヴェレット）は、1988年創業の仲吉商事株式会社が展開する天然素材のテーブルウェアブランドです。天然孟宗竹を使い、素材の育成から製品開発・製造・販売までを自社で一貫して手がけているのが特徴です。竹・木製でありながら食洗機に対応する独自のコーティング技術を採用しており、ジェイアール京都伊勢丹やロフト各店など有名百貨店・商業施設での取り扱いも多数あります。

同社は、大人向けのRIVERETのほか、ベビー・こども用食器の「agney*（アグニー）」、普段使い・飲食店向けのシンプル食器「taffeta（タフタ）」もあわせて展開しており、結婚祝い・出産祝い・退職祝いなど幅広いギフトシーンに対応しています。オーダーメイドの名入れ加工に対応している商品もあります。

メリット

良い評判として多く見られる点

  • 「安すぎず高級すぎない、ちょうどいいギフト」という贈り物としての評価が高い
  • 竹・木製ながら食洗機対応という、ナチュラル食器では珍しい実用性
  • 結婚祝い・出産祝い・退職祝いなど、シーンに合わせてRIVERET・agney*・taffetaを選べる幅広さ
  • オーダーメイドの名入れ加工に対応でき、被りにくいギフトになる点

気になる点

  • マグやボルドーなど人気アイテムは4,000円〜5,000円台が中心で、一般的な食器と比べると価格はやや高めという声がある

価格については、天然素材ならではの質感や食洗機対応という機能性を踏まえると納得できるという受け止め方をする利用者が多いようです。まずは1点、贈り物や自分用に試してみるという選び方もできます。

デメリットと対策

価格の他には、天然素材ゆえに一点ごとに木目や色合いに個体差があり、写真のイメージと届いた商品の印象が異なる場合がある点にも留意が必要です。

気になる場合は、商品ページの写真・レビューを複数確認したうえで、公式通販サイトから購入するとよいでしょう。
