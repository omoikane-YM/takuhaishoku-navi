KISEKI:とは

刃物の産地として知られる岐阜県関市の福田刃物工業株式会社が手がける包丁ブランドです。刃の素材に「超硬合金」というダイヤモンドに次ぐ硬度を持つ素材を採用しており、一般的なステンレス包丁と比べて研ぎ直しの頻度を大幅に減らせる点が特徴です。

持ち手には岐阜県産のブナ・ミズナラ・ヤマザクラなど天然木を使用し、機能性と質感を両立しています。

メリット

良い評判として多く見られる点

  • りんごやキャベツ、バゲットなどが潰れずスッと切れるという切れ味への評価が多い
  • 野菜の切り口が変色しにくいという口コミ
  • 錆びにくく長く使える耐久性があるという評判
  • 天然木の持ち手による、あたたかみのある高級感のあるデザイン

気になる点

  • 硬度が高い分、刃こぼれしやすく、冷凍食品や骨付き肉、かぼちゃなど硬いものを切るのには不向きという声がある

刃こぼれについては、対象外の硬い食材は避けて調理用途を使い分けている利用者が多いようです。一般的な砥ぎ器では研げない素材のため、公式の「里帰り研ぎ直しサービス」を利用して切れ味を維持する使い方が見られます。

デメリットと対策

刃こぼれのしやすさの他には、一般的なステンレス包丁と比べて価格が高めである点にも留意が必要です。これは超硬合金という特殊な素材と職人の手仕事によるコストと考えられます。

冷凍食品や硬い食材を切る機会が多い方は、普段使いの包丁と使い分けるとよいでしょう。

こんな人におすすめ

  • 切れ味が長持ちする、長く使える本格的な包丁を探している方
  • 野菜や果物を美しい切り口で仕上げたい方
  • 職人技が光る、質感の良い調理道具にこだわりたい方
  • 宅配食材・ミールキットの下ごしらえを気持ちよく行いたい方
