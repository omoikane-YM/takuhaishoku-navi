コープ自然派とは

コープ自然派事業連合が運営する生協の個人宅配サービスです。食の安心・安全を第一に考え、独自の取り扱い基準と情報開示を徹底しているのが特徴で、取り扱う農産物の約65％が有機・無農薬栽培だと公式サイトで公表されています。

食品添加物にできるだけ頼らないプライベートブランド「自然派Style」を展開しているほか、年間450種類のレシピから提案される国産野菜のミールキットも用意されています。

対応エリア・はじめての特典

2026年9月時点の公式サイト公開情報です。最新の対応エリア・特典内容は必ず公式サイトでご確認ください。

項目内容
対応エリア 徳島県・香川県・高知県・愛媛県・大阪府・兵庫県・奈良県・京都府・滋賀県・和歌山県（一部地域を除く）
はじめてボックス 定番セレクト・人気セレクトの2種類、通常価格から約30％OFF

注文方法 紙のカタログのほか、スマホ・パソコンからのオンライン注文にも対応

加入には出資金の払い込みが必要な生協形式のため、金額や手続きの詳細は公式サイトで確認することをおすすめします。

メリット

良い評判として多く見られる点

  • 取り扱う農産物の約65％が有機・無農薬という高い比率
  • 食品添加物に頼らないプライベートブランド「自然派Style」で安心感がある
  • 妊娠中・1歳未満のお子さんがいる家庭は配達手数料が最長1年間無料
  • スマホ・パソコンからのオンライン注文に対応し、忙しい家庭でも使いやすい

気になる点

  • 対応エリアが四国・関西の一部地域に限定されている

対応エリア外だと利用できないため、申し込み前に必ず公式サイトで配達エリアを確認しておくと安心です。

デメリットと対策

対応エリアの限定以外にも、生協という仕組み上、加入時に出資金の払い込みが必要になる点に注意が必要です。また、1世帯での申込は1回に限られ、代理での申込やお試しセットのみの購入は新規加入特典の対象外となっています。

出資金の金額や脱退時の取り扱いについては公式サイトのFAQで事前に確認しておくことをおすすめします。
