坂ノ途中とは

「100年先も続く農業を」というメッセージを掲げ、環境への負荷の小さい持続可能な農業を広めるために活動している京都の野菜提案企業です。少量不安定な生産になりがちで販路不足に悩むことが多い新規就農者や若手農家のパートナーとして活動しているのが特徴で、野菜は京都をはじめ関西の農家を中心に届けられています（一部、九州・四国の農家の野菜も含まれます）。

取り扱う農産物は栽培期間中、化学合成農薬・化学肥料不使用で育てられたものが中心です（一部、有機JAS認証で使用が認められた生物農薬を使用する場合があります）。有機JAS認証の取得有無自体は重要視せず、自社で使用資材や栽培履歴を確認するという方針を取っているのも特徴の一つです。

お野菜セット（1回お届け） 「お野菜をたのしむ朝のセット」「お野菜をシンプルに味わうセット」など、はじめての方向けに送料無料で試せるセットを用意

産地直送商品の一部は「送料込」表記があるなど、商品によって送料の扱いが異なるため、注文前に商品ページで確認しておくと安心です。

メリット

良い評判として多く見られる点

  • 新規就農者・若手農家をパートナーに、バリエーション豊かな野菜セットを届ける独自の取り組み
  • 化学合成農薬・化学肥料不使用で育てられた農産物を中心に取り扱う環境配慮型の農業
  • 毎週水曜日にラインナップが更新され、旬の野菜を楽しめる
  • はじめての方向けに送料無料の1回お届けセットが用意されており、定期宅配前に試しやすい
  • 野菜だけでなくお米・コーヒー・調味料・おやつなど幅広い商品から選べる

気になる点

  • 公式サイト上に配送対応エリアの明記が見当たらず、事前確認が必要

対応エリアや配送スケジュールの詳細は、注文前に必ず公式サイトの「ご注文の流れ」やよくある質問でご確認ください。

デメリットと対策

公式サイトには対応エリアや送料についての明確な一覧が見当たらず、商品ごとに送料の扱いが異なる点にも注意が必要です。産地直送の商品は「送料込」と明記されているものが多い一方、通常のお野菜セット・定期宅配については商品ページ内での確認が必要になります。

まずは送料無料の「1回お届け」セットで野菜の味や量を確認し、自分や家庭に合いそうであれば定期宅配へ切り替える、という流れで検討すると失敗しにくくなります。

こんな人におすすめ

  • 有機・低農薬など環境に配慮した野菜にこだわりたい方
  • 新規就農者・若手農家を応援したい方
  • 季節ごとに変わる旬の野菜を楽しみたい方
  • 野菜だけでなくお米やコーヒーもまとめて定期購入したい方
  • まずはお試しセットから始めて、自分に合うか確認したい方
