おうちコープとは

神奈川県・静岡県・山梨県の生協「生活協同組合ユーコープ」が運営する、生協の個人宅配サービスです。生鮮食品から揚げるだけ・温めるだけの時短調理品、生協オリジナルブランドの卵や肉まで、約3,000品目を取りそろえているのが特徴です。

注文はメインカタログ「お買物めも」のほか、スマホの注文アプリからスキマ時間に済ませることもでき、留守時は置き配での受け取りにも対応しています。

対応エリア・料金

2026年9月時点の公式サイト公開情報です。最新の対応エリア・料金は必ず公式サイトでご確認ください。

項目内容
対応エリア 神奈川県・静岡県・山梨県（一部地域を除く）
宅配料 1回のご利用が3,500円（税込）以上で110円（税込）、3,500円未満で198円（税込）
受け取り方法 在宅受け取りのほか、留守時の置き配にも対応
注文方法 紙のカタログ「お買物めも」のほか、スマホの注文アプリにも対応
割引制度 子育て家族・シニア向けなど、条件を満たすとお得な割引制度あり

メリット

良い評判として多く見られる点

  • 約3,000品目という生協ならではの豊富な品揃え、オリジナルブランドの卵や肉など違いを実感できる商品も
  • 揚げるだけ・温めるだけの時短調理品が充実しており、忙しい日でも助かるという声
  • 1回3,500円（税込）以上の利用なら宅配料が110円に抑えられる
  • 留守時は置き配で受け取れ、スマホの注文アプリでスキマ時間に注文できる

気になる点

  • 対応エリアが神奈川・静岡・山梨の一部地域に限定されている

対応エリア外だと利用できないため、申し込み前に必ず公式サイトで配達エリアを確認しておくと安心です。

デメリットと対策

対応エリアの限定以外にも、生協の宅配サービス全般に言えることですが、毎週決まった曜日・時間帯に配達される仕組みのため、受け取りのタイミングを事前に把握しておく必要があります。配達の曜日や時間帯、留守時の置き配の可否については、公式サイトのよくある質問で確認しておくとスムーズです。

  • 時短調理品を活用して家事の負担を減らしたい子育て世帯
  • オリジナルブランドなど生協ならではの品質にこだわりたい方
