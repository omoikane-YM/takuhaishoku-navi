casaneo(カサネオ)とは

洋菓子ブランドを展開する株式会社シュゼットが運営する、ミルクレープ専門ブランドです。1988年、casaneoのシェフが麻布のレストランで発明したのが日本におけるミルクレープの始まりとされており、透けるほど薄いクレープを20層重ねる製法で楽天ランキング1位（ケーキ部門）を受賞しています。

2025年には、クリームや果肉、クッキーなどの素材を分厚い層でたっぷり重ねた新シリーズ「ミルクリーム」も登場し、従来のミルクレープとは違った新食感のスイーツも楽しめます。店舗は現在、東京（ルミネ北千住店・ラゾーナ川崎店）と大阪（梅田阪急店）のみのため、店舗が近くにない方にとって公式通販は貴重な購入手段です。
