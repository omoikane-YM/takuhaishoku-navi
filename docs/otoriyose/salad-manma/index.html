サラダまんまとは

TNAソリューションデザイン株式会社が展開する、独自の特許製法によって粉末化した野菜をお米にコーティングした商品です。いつものお米と一緒に炊くだけで、偏食や少食、野菜嫌いなお子様の不足しがちな栄養を手軽にサポートできる「魔法のひとふり」がコンセプトになっています。

特許製法により、個人差のある「噛む力」に左右されずに野菜の成分を摂取できることから、サラダや野菜ジュースよりも消化吸収率が良いとされています。厳選された国産野菜を使用し、保存料・着色料・香料は一切不使用。炊飯前のお米についている色味は野菜の成分によるものです。

メリット

公式サイトで訴求されている特長

  • いつもの白米に混ぜて炊くだけの手軽さで、特別な調理の手間がかからない
  • 特許製法によりお米にコーティングされているため、野菜の味や食感が苦手な子どもにも気づかれにくい
  • 厳選された国産野菜を使用し、保存料・着色料・香料は一切不使用
  • 「無理に食べさせなくていい」という、日々の食事作りをするご家庭の心の負担軽減を目的にしている

気になる点

  • 初回購入後は自動継続する定期コースのため、休止・解約のタイミングをあらかじめ確認しておく必要がある

休止・解約は次回出荷予定日の7日前までにマイアカウントから手続きできるため、届くタイミングをカレンダー等で把握しておくと安心です。

デメリットと対策

定期コースの解約タイミング以外では、商品の特性上お客様都合での返品・交換・返金は受け付けていない点にも注意してください。到着後は内容・数量を確認し、不備があれば到着後2日以内に問い合わせるルールになっています。
