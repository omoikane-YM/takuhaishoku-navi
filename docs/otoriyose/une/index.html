une onlineshopとは

「心弾む、とっておきな時間のお届け」をコンセプトに、株式会社ニッチが運営するチョコレート専門ブランドの通販サイトです。看板商品はチョコレートサンドウィッチ「cacaosic（カカオシック）」で、空気を含む特別な製法によって、重たすぎずなめらかな口どけのチョコレートに仕上げています。

厚さ10mmのチョコレートが溶けだすのと同時に、中に含まれた空気とピスタチオなどの香りが広がる新食感が特長。サクサクのラングドシャと重なることで、1つでも満足感のあるお取り寄せスイーツになっています。季節限定のモンブラン味など、旬のフレーバーが登場するのも魅力です。

メリット

公式サイトで訴求されている特長

  • 空気を含ませる独自製法により、厚みがありながら重たすぎないなめらかな口どけ
  • ラングドシャとチョコレートを重ねた新食感で、1つでも満足感のある贅沢さ
  • モンブランなど季節限定フレーバーが登場し、通年で新しい味わいを楽しめる
  • 冷凍配送で品質を保った状態で届くため、手土産やギフトにも活用しやすい

気になる点
