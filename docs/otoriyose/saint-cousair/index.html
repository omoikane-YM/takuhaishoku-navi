サンクゼール&久世福商店オンラインショップとは

食を中心とした心地よいライフスタイルを提案する株式会社サンクゼールが運営する公式オンラインショップです。長野県飯綱町の自社工場で作るオリジナルワイン・ジャム・パスタソースなどを中心とした「サンクゼール」と、万能だしをはじめとする調味料・お酒・お菓子・珍味など和をテーマにした「久世福商店」の2ブランドを、1つのサイトでまとめて購入できます。

めざましテレビやZIP!、ヒルナンデス！など数多くのメディアで取り上げられており、お中元・内祝いなどのギフト用途でも高い評価を得ています。

メリット

デメリットと対策

購入方法による条件の違い以外には、ジャム・お菓子など季節限定・数量限定の商品は早期に売り切れる場合があります。気になる商品を見つけたら、在庫があるうちに注文を検討するとよいでしょう。
