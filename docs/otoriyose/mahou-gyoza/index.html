魔法の焼き餃子とは

創業24年の大阪中華の名店「幸福飯店」が手がける、株式会社ハッピーフードシステムの冷凍点心専門通販サイトです。餃子・水餃子・小籠包などの点心を、点心師歴約40年・日本在住25年以上の職人がひとつひとつ手包みしており、焼き立てはもちろん冷めてももちもち食感が続くのが特長です。

餡には鹿児島県産のブランド豚「薩摩茶美豚（チャーミトン）」を使用。HACCPの考え方を取り入れたJFS-B規格に基づく衛生管理体制のもとで製造されており、化粧箱・熨斗・メッセージカードに対応したギフトセットも用意されています。

メリット

良い評判として多く見られる点

  • 皮までひとつひとつ手包みされた本格点心を、自宅にいながら味わえる
  • 国産ブランド豚「薩摩茶美豚」の上品な甘みの脂が、餃子の餡との相性が良いという評価
  • JFS-B規格に基づく衛生管理体制で製造されており、安心して食卓に出せる
  • 化粧箱・熨斗・メッセージカードに対応しており、母の日・内祝いなどのギフト利用にも向いている

気になる点

  • 送料が全国一律1,100円かかり、まとめ買いをしないと1回あたりの送料負担がやや大きく感じられる場合がある

30ヶ入りなど大容量セットを選べば、1個あたりの実質コストは抑えやすくなります。冷凍保存できるため、まとめ買いしてストックしておく利用の仕方もよさそうです。

デメリットと対策

送料以外では、冷凍配送の食品のため到着後は冷凍庫で保管し、解凍方法は公式サイトの案内（蒸し器またはフライパンでの調理が推奨、電子レンジ用蒸し器での調理は非推奨）に従うのがおすすめです。注文はLINEからは受け付けていない点にも留意してください。
