おせちの千賀屋とは

創業55周年、割烹料亭千賀の総料理長「千賀信明」氏が監修する迎春おせちを、全国にお届けする通販ブランドです。累計製造販売数は500万セット以上、365日おせち作りに励むトップメーカーとして、重箱も自社製造にこだわっています。

中国産主原料不使用・合成保存料不使用・合成着色料不使用を掲げ、原料メーカー出荷時から出荷前まで細菌検査・食味検査を重ねる管理体制を公式サイトで公表しています。おせち以外にも生ずわい蟹や飛騨牛、鹿児島黒牛セットなど、単品のお取り寄せグルメも展開しています。

価格・ラインナップ

2026年9月時点の公式サイト公開情報です（2027年お届け分）。最新の価格・予約状況・お届け日は必ず公式サイトでご確認ください。おせちは年末年始にお届けする季節商品のため、通年での取り扱いではありません。

メリット

良い評判として多く見られる点

  • 創業55周年・累計500万セット以上という実績に裏付けられた老舗の味
  • 割烹料亭千賀の総料理長監修による、料亭の味わいを自宅で楽しめる

デメリットと対策

季節限定である点のほか、変更・キャンセルの受付は11月30日正午までと期限が決まっているため、注文内容は余裕を持って確定させておくと安心です。また公式サイトが詐欺サイトへの注意を呼びかけているとおり、購入は必ず公式の販売ページから行うようにしましょう。
