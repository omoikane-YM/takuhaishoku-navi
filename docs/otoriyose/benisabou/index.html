紅茶房（べにさぼう）とは

福岡県久留米市のカフェ「imoyaみ乃う茶房」がプロデュースする、九州産紅はるかの焼き芋専門店です。福岡・鹿児島・熊本など産地ごとの紅はるかを、収穫後1,000時間以上かけて泥付きのまま熟成させ、低温でじっくり焼き上げることで、自然な甘みと上品な味わいを引き出しています。焼く直前まで新鮮さを保つ真空包装や、無着色・保存料不使用・砂糖不使用へのこだわりも特徴です。

テレビ番組「めざましどようび」での紹介や、雑誌『ソワニエ+』『シティ情報Fukuoka』など多数のメディア掲載実績があり、SNSでも話題になっている焼き芋・芋スイーツ専門店です。

メリット

良い評判として多く見られる点

  • 1,000時間以上の熟成と低温調理による、砂糖不使用でも感じられる自然な甘さ
  • 無添加・無着色・保存料不使用へのこだわりで、家族みんなで楽しみやすい
  • 福岡・鹿児島・熊本など産地別の食べ比べができるセットが人気
  • テレビ・雑誌など多数のメディア掲載実績があり、贈答用としても選ばれている

気になる点

  • 芋スイーツとしては客単価5,000円程度とやや高単価な価格帯

価格はやや高めですが、14日間の返金保証が用意されているため、初めての方でも試しやすい仕組みになっています。まずは食べ比べセットから試すのもおすすめです。

デメリットと対策

価格帯の他には、冷凍便での配送となるため、到着後は解凍方法を公式サイトの案内に従うのがおすすめです。暑い時期は半解凍でひんやりとしたデザート感覚でも楽しめるという紹介もされています。eギフト・法人注文は通常の注文方法と条件が異なる場合があるため、購入前に公式サイトの注意事項を確認するとよいでしょう。
