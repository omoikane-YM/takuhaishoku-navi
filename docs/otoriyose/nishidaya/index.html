京つけもの ニシダやとは

創業89年の歴史を持つ、京都の伝統的な漬物を製造・販売する老舗です。看板商品「おらがむら漬」は、しば漬の茄子を胡瓜に変え、生姜・茄子・茗荷・紫蘇の葉とともに漬け込んだ商品で、年間約60万個を売り上げる人気商品です。

さわやかな酸味と胡瓜のぱりぱりとした食感が特徴で、京都人の選ぶ手土産ランキングで上位に入るなど、地元でも評価の高いブランドです。
