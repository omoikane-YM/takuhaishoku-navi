博多久松とは

昭和57年創業、「食」を中心とした製品づくりとサービスを展開する福岡・博多発の食品ブランドです。看板商品であるおせち料理は累計150万セットを突破し、某大手通販モールでは12年連続で賞を受賞するなど、通販おせちの分野で高い評価を得ています。

フジテレビ「景気満開テレビ」やTBS「Nスタ」、女性セブンなど数多くのメディアにも出演・掲載されており、おせちのほかご飯のお供、お食い初めセット、博多牛もつ鍋など幅広い商品を展開しています。

メリット

良い評判として多く見られる点

  • おせち累計150万セット突破、某モール12年連続受賞という実績・信頼性
  • おせちだけでなく、お食い初めセットや牛丼セット、ご飯のお供まで幅広い商品展開
  • 数々のテレビ・雑誌メディアでの紹介実績があり、認知度・安心感が高い
  • 贈答・お祝い事に対応した熨斗アート・ギフト梱包などの気配り

気になる点

  • 看板商品のおせちは季節限定（新春向け）のため、通年で楽しめる商品は牛丼セットやご飯のお供など一部に限られる

おせち以外のシーズンでも、絶品ご飯のお供シリーズやこだわり牛丼セットなど、日常使いできる冷凍・常温商品が揃っているため、年間を通じて楽しめます。

デメリットと対策

おせちは商品の性質上、150日以内の入金確認・商品受け取りが必要になるなど、通常商品と比べて余裕を持った注文・受け取りスケジュールの確認が必要です。また冷凍便でのお届けとなる商品が多いため、解凍方法や消費期限は商品到着時に必ず確認するとよいでしょう。
