ちこり村本店サイトとは

岐阜県中津川市で「ちこり村」を運営する株式会社サラダコスモが手がける公式オンラインショップです。看板商品の「ちこり村田舎の手づくりおせち」は楽天おせちセットランキングで14年連続1位、楽天グルメ大賞を2度受賞するなど高い評価を得ており、毎年早期に完売する人気商品となっています。

おせちのほかにも、機能性表示食品×オーガニック認証の「有機黒にんにく」（リピート率94%）や、ジャパンフードセレクション2024年グランプリを受賞した「栗きんとん生食パン」など、地元の生産者と連携した自然派「食」の商品を幅広く展開しています。

価格・商品ラインナップ

2026年9月時点の公式サイト公開情報です。おせちは年末限定の季節商品のため、注文期間・在庫状況は公式サイトで必ずご確認ください。

メリット

良い評判として多く見られる点

  • 看板のおせちは楽天ランキング14年連続1位・グルメ大賞2度受賞という客観的な実績がある
  • 薄味仕立てでうま味たっぷりという味付けへの評価が多い
  • 有機黒にんにくや栗きんとん生食パンなど、健康志向・話題性のある商品も揃う
  • 冷蔵便・冷凍便あわせて4種類のサイズからおせちを選べる

気になる点

  • 人気のおせちは毎年早期に完売するため、購入を決めている場合は早めの予約が必要

おせちの予約開始時期は例年9月中旬頃からとされているため、確実に手に入れたい場合は公式サイトのお知らせをこまめに確認するとよいでしょう。

デメリットと対策

早期完売の可能性以外では、冷蔵便・冷凍便の商品が中心のため、到着後は商品ごとの保存方法（冷蔵・冷凍）に従い、できるだけ早めに消費することをおすすめします。栗きんとん生食パンなど常温便の商品も消費期限が出荷日＋4日と短めのものがあるため、あわせて確認しておくと安心です。
