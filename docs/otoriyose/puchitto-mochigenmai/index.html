ぷちっともち玄米とは

長期保存食・アルファ化米で30年以上の通信販売実績を持つアルファー食品株式会社が手がける、玄米製品です。100％国産のもち米を使用しており、通常の玄米にありがちなパサパサ感や臭みが少なく、もちもちとした食感が楽しめるのが特徴。独自製法により、白米と同じように洗米・つけ置き・蒸らし時間なしで炊飯できます。

食物繊維やビタミンB1、マグネシウムなど白米と比較して多く含まれる栄養素を、無理なく摂取できる点も支持されています。学校給食でも採用されており、ヴィーガン認証も取得済みです。

価格・炊き方

アレンジ ゆでてグレインズサラダやスープご飯、炊き込みご飯など幅広い料理にも活用可能

メリット

良い評判として多く見られる点

  • 洗米・つけ置き・蒸らし時間が不要で、白米と同じ感覚で炊飯できる手軽さ
  • 100％国産もち米ならではのモチっとした食感で、玄米特有のパサパサ感が少ない
  • 食物繊維やビタミンB1、マグネシウムなど、白米と比較して多い栄養素を摂取しやすい
  • カレーや炊き込みご飯、グレインズサラダなど和食以外にも幅広くアレンジできる

気になる点

  • 通常の白米と比べると価格はやや高め

価格差はありますが、洗米や浸水の手間がかからない分の時短効果や、栄養面でのメリットを考慮すると許容範囲という声もあるようです。まずは白米とのブレンドから試すと、コストと食べやすさのバランスを取りやすいでしょう。

デメリットと対策

価格の他には、早炊き機能（早炊き・白米急速・快速・高速）での炊飯は公式に非推奨とされている点にも注意が必要です。うまく炊飯できない場合があるため、通常モードまたは炊き込みモードでの炊飯をおすすめします。タイマー予約で長時間浸水させる場合は、玄米ブレンドの比率を3割程度までにとどめるとよいでしょう。

こんな人におすすめ

  • 玄米に興味はあるが、炊飯の手間や食感が気になっていた方
  • 白米とのブレンドから無理なく玄米食を取り入れたい方
  • お子様や家族にも食べやすい玄米を探している方
  • ヴィーガン対応の国産米を探している方
