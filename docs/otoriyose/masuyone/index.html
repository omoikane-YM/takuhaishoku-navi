越前かに問屋ますよねとは

有限会社増米商店が運営する、創業65年超の海鮮問屋によるカニ・うなぎなどの通販サイトです。楽天市場のカニ通販ランキングでも常連として名を連ねる実績があり、シーズンには楽天総合ランキング上位に入ることもあります。

元祖カット済みの生本ずわい蟹など、下処理済みで食べやすい商品も展開しています。

メリット

良い評判として多く見られる点

  • 「カニ肉がぎっしり詰まっていて美味しい」という品質への評価が多い
  • 「身がぷっくり盛り上がっており、他社の冷凍解凍のカニとは違う」という口コミ
  • カスタマーサービスの対応が良いという評判
  • カット済みの生本ずわい蟹など、下処理の手間を省ける商品がある

気になる点

  • 「去年より小さい」など、年やシーズンによって内容量の印象に差があるという声がある

カニは天然の水産物のため、漁獲状況によってサイズ・価格が変動しやすいという性質を理解した上で購入している利用者が多いようです。口コミには「甘くて身もしっかりしている」と満足する声もあり、年によって差はあるものの総じて高評価が多い傾向にあります。

デメリットと対策

サイズの変動の他には、生鮮食品のため到着後は早めに食べきる必要がある点にも留意が必要です。

解凍方法によって味・食感が変わるため、公式サイトの推奨する解凍方法を確認してから調理するとよいでしょう。

こんな人におすすめ

  • 本格的なカニを自宅で楽しみたい方
  • 下処理済みで手軽に食べられるカニを探している方
  • 実績のある海鮮問屋から安心して購入したい方
  • 特別な日のごちそうにカニ・うなぎを取り入れたい方
