孤高のキャンプ飯とは

長期保存食「安心米」シリーズなどを手がけるアルファー食品株式会社が展開する、キャンプ・登山・アウトドア専用のアルファ化米です。国産うるち米を独自製法（アルファ化加工）で加工しており、洗米やつけ置きをしなくてもお湯や火にかけるだけで炊きたてのご飯が食べられます。

1袋0.5合の食べきりサイズで、メスティンやシェラカップにそのまま収納できるスタッキングのしやすさが特長。強風でコンロの火が安定しない、燃料が切れたといった「いざ」という時には、水を注ぐだけでも調理できる点も、アウトドアならではの不測の事態に配慮した設計です。

内容量 0.5合×8袋入り

熱源がない場合の調理法 水約100mLを注ぎ、90分程度待つだけで食べられる

メリット

公式サイトで訴求されている特長

  • 洗米・つけ置きが不要で、通常のお米より熱にかける時間も短く、時短と燃料の節約につながる
  • 通年で一定の水加減で炊飯できるため、新米か古米かで加減が変わる通常のお米と比べて初心者でも失敗しづらい
  • 1袋0.5合の食べきり量なので無駄がなく、人数に応じて袋数を調整しやすい
  • 強風で火が安定しない、燃料切れといった不測の事態でも、水を注ぐだけで調理できる

気になる点

  • 公式サイトでは加熱調理を前提とした商品と案内されており、お湯戻しでの調理は推奨されていない

水のみでの調理もできますが、よりおいしく食べたい場合は公式が案内する加熱調理（メスティン・シェラカップでの炊飯）を基本にするとよさそうです。

デメリットと対策

調理方法の指定以外では、開封後は保管をせずに早めに食べきる必要がある点にも注意が必要です。通常のお米よりも長期保存が可能な設計のため、キャンプ用に使い切らなかった分を普段の備蓄用に回すといった活用の仕方もできそうです。

こんな人におすすめ

  • キャンプや登山の荷物を少しでもコンパクトにしたい方
  • 洗米や水加減の調整が面倒で、失敗なく炊飯したい方
  • ソロキャンプなど、食べきりサイズのごはんを探している方
  • アウトドアだけでなく、日常の備蓄用にも活用したい方
