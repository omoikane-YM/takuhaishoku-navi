熊本馬刺しドットコムとは

株式会社利他フーズが運営する馬刺し・馬肉の通販専門サイトです。6,600店以上の飲食店にも卸してきた実績を持ち、馬刺し通販の年間売上でトップクラスの評価を得ています。

公式サイトでは「公式を装う偽アカウント・詐欺サイトに注意」との注意喚起も出されており、購入の際は公式サイト・公式SNS経由であることを確認するとよいでしょう。

価格帯

2026年9月時点で公開情報から確認できた価格の目安です。最新の金額は必ず公式サイトでご確認ください。

商品は920円程度の少量セットから、14,980円程度の大容量・詰め合わせギフトセットまで幅広く展開されています。用途（自宅用・ギフト用）や量に応じて選べる価格帯です。
